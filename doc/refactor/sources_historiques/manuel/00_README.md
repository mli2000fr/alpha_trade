# 📖 Manuels utilisateur — Alpha Trade IHM

> **Public visé** : utilisateur débutant, n'ayant **jamais** utilisé
> l'application, et ne connaissant **pas** ou peu les outils financiers.
> Tous les manuels supposent que vous utilisez **exclusivement l'IHM**
> (interface graphique Streamlit). Aucune commande clavier n'est requise sauf
> au tout premier démarrage.

## ⚠️ Avertissement préalable

Cette application **n'est pas un conseil en investissement**. Le trading
boursier comporte un risque de **perte totale** du capital. Les manuels
ci-dessous sont pédagogiques et techniques. Avant tout passage en argent
réel, lisez impérativement [`52_securite_et_argent_reel.md`](52_securite_et_argent_reel.md).
