# Synthèse de clôture — E6 → E13 (2026-08-20)

**Branche : recherche « Oracle Extreme → monétisation LONG ». STATUT : FERMÉE.**
**Baseline research gelée : Oracle O0 → Extreme TOP20 → LONG-only → PROD lifecycle → m24 → equal-weight 1/24 (budget de risque total constant).**

Ce document raconte la **chaîne causale** E6→E13 (pas une succession de backtests), conserve
explicitement les **NO-GO** (qui valent autant que le GO m24), distingue les deux lifecycles, et
fixe le **risque résiduel officiel 2026H1**.

## 1. Résumé exécutif

La recherche a testé **cinq leviers** pour transformer l'univers Oracle Extreme en stratégie
monétisable. Un seul passe un gate pré-fixé : la **diversification (capacité)**.

| Levier | Verdict | Preuve |
|---|---|---|
| Directionnel Y3-LONG | **NO-GO** | AUC 0.572 (ML) mais E7 : 37% vs 150% sans Y3 |
| EV / Platt | **NO-GO** | E6-B4 : EVSORT ≈ RANK20 (pur ranking) |
| NO-TRADE (TRUE_BAD) | **NO-GO** | E12-1A : TRUE_BAD ~20% non séparable à l'entrée (AUC≤0.60, ratio$≤0.73) |
| Exits (stop initial / trailing) | **NO-GO** | E12-2B : stop initial inerte ; E12-2C : trailing négatif |
| **Capacité / diversification** | **GO (m24)** | E13/E13-B : dispersion inter-seed −59%, P10 14.6→41.7, pire seed +23.5, PF/DD/Sharpe préservés |

**Message central :** m24 n'améliore **pas** le signal prédictif. Il améliore sa **monétisation**.
L'edge se trouve dans **l'appartenance à l'univers Extreme** (le gate), et la diversification
réduit le **risque d'échantillonnage** créé par la sélection d'un petit nombre de titres (m8
prélève 8/79 candidats quasi équivalents). → **Ne pas repartir chercher un ranker.**

## 2. La chaîne causale E6 → E13

### E6 — Tentative directionnelle (Y3-LONG)
- Backfill H2, labels de chemin Y3, walk-forward 2023-2026, CatBoost+LGBM sur 176 features O0.
- **ML : GO** (AUC 0.572 sur folds, H2 couvert). Calibration Platt gagne (ECE 0.048 vs 0.312).
- **Portefeuille : NO-GO** dès E6-B2→B4 (EV_LONG pire), E6-C retient RANK_TOP20 (37.5%) vs TOP10 (45.1%) car la tranche 10-20% est diversifiante.

### E7 — Le filtre Y3 DÉTRUIT le portefeuille
- NO_Y3 149.9% vs WITH_Y3 37.5%. Le modèle directionnel filtre les gros mouvements qui portent l'edge.

### E8 — L'edge est le GATE, pas le ranking
- Le rang interne n'est pas monotone ; random ≈ oracle dans le pool (Q2) ; SHORT catastrophique (−86.8%).
- **Le gate Extreme (top 20% de `proba_extreme`) est l'edge.** Le classement interne est secondaire.

### E9 / E10 — Le gate est réel mais la variance seed est énorme
- Gate 6/6 gates, mais variance de seed catastrophique (78%↔171%).
- 20 seeds : NO_GATE méd 42.8% vs TOP20 méd **124.8%** (PF 1.26, 95% seeds > NO_GATE), **mais** P10 36% / P90 193% (dispersion 157 pts) et 2026H1 mauvais (30% seeds positifs).

### E11 — Diagnostic payoff + sélection (sous E-LIFECYCLE)
- Payoff : TP +588k vs trailing −183k / stop −180k / time −85k.
- Variance : m8 ≈ **échantillonnage aléatoire** (Jaccard <1% entre seeds) ; le pool n'est **pas** fat-tail jackpot (top-1 = 4% de la somme du jour).
- 2026H1 (sous E-LIFECYCLE) : MFE médian normal (9.0%) mais MAE profonde (−10.9%, ratio 1.21), stops 41% → narrative « bons candidats mal monétisés ».

### E12-A0 — Audit du contrat d'exécution : E-LIFECYCLE ≠ PROD
- **5 divergences substantives** : stop initial 3.5 vs 2.5×ATR, TP min(4×ATR,13%) vs min(3×ATR,7%), trailing 7%/J1 vs 2.5×ATR/J+1, time_stop ON vs neutralisé, gap filter OFF vs 3%.
- Les **229 time_stop d'E11 sont un artefact du moteur recherche** (la production n'en exécute jamais : 0 fills sur les runs parity).

### E12-A0b — Recheck E11 sous PROD : la narrative s'inverse
- Sous PROD, 2026H1 : medMAE **−6.7%** (NORMAL), ratio MAE/MFE 0.91. **Le « MAE profonde » était un artefact du stop large 3.5×ATR.**
- 2026H1 = surtout des **mauvaises entrées** (MFE<3% puis perte = −71.2k, 24% des trades) ; premature stops négligeables (−9.8k).
- Le stop-leak structurel (stops mangent ~89% des gains TP) existe sur **tous** les semestres, pas spécifiquement 2026.

### E12-1 — Vraies erreurs d'entrée (TRUE_BAD) : NON SÉPARABLES
- TRUE_BAD (mfe<3% ET perte) = **20.4% structurel** (18-24% chaque semestre).
- 16 features PIT (Oracle, ATR, momentum, breadth, vol, gap…) : AUC ≤ 0.60 ; **aucun filtre rentable à aucun seuil** (ratio$ max 0.73 < 1, NET toujours négatif). → Pas de NO-TRADE.

### E12-2 — Exits : NI stop initial, NI trailing
- **E12-2B** : stop initial élargi (3.0/3.5/4.0×ATR) = **zéro effet** (le trailing 2.5×ATR est le stop liant, re-étiquetage init→trailing au même prix).
- **E12-2C** : trailing élargi = **négatif** (conversion en initial_stops profonds, DD +, 2026H1 + mauvais, 2025H1 détruit). Le contrefactuel trade-level E12-2A (qui semblait positif) ignorait la liaison du stop initial + la capacité.
- → Les pertes de stops sont le **coût normal de la protection**, pas un gisement.

### E13 / E13-B — Capacité / diversification : GO (m24)
- Même univers, même lifecycle, **risque total constant** (equal-weight 1/m). Une seule variable : le nombre de positions.
- E13 (20 seeds) : dispersion P90−P10 113→47 (−59%), std 44.2→19.5 (−56%), P10 14.6→41.7, pire seed −9.1→+23.5, 100% seeds positifs, PF 1.14 inchangé, DD −26.0→−22.5.
- **E13-B (50 seeds, gate pré-fixé) : m24 = baseline confirmée.** medRet 61.6% (m16 64.5), P10 41.1 (m16 32.3), pire seed +23.5 (m16 +8.4), disp 47 (m16 70), std 18.5 (m16 27.6), PF 1.13, DD −22.6, Sharpe 0.45. m16 = challenger secondaire.

## 3. NO-GO explicites (à ne PAS réintroduire sans un nouveau protocole)

- **Pas de `global_rank_20` comme source de l'edge** (le rang interne ne porte pas la valeur).
- **Pas de Y3 directionnel en production** (filtre destructeur, E7).
- **Pas de Platt/EV_LONG** (pur re-ranking, E6-B4).
- **Pas de filtre NO-TRADE / TRUE_BAD** (non séparable, E12-1A).
- **Pas de modification TP/SL/trailing** (initial inerte, trailing négatif, E12-2B/C).
- **Pas de SHORT** (chantier séparé, −86.8% en E8, MAE −16.5%).

## 4. Distinction CRITIQUE des lifecycles

Ne jamais comparer un résultat E6→E11 à un résultat E12+ sans préciser le lifecycle.

| Champ | E-LIFECYCLE (E6→E11, recherche) | PROD lifecycle (E12+, canonique) |
|---|---|---|
| initial stop | 3.5×ATR | **2.5×ATR** |
| TP | min(4×ATR, 13%) | **min(3×ATR, 7%)** |
| trailing | max(3.5×ATR, 7%), armé J1 | **2.5×ATR risk-based, armé J+1 (watcher)** |
| time_stop | ON 15j (229 exits = artefact) | **OFF / neutralisé (0 fills)** |
| gap filter | OFF | **3%** |
| intrabar / entry / costs | conservative / next_open / 16bps | conservative / next_open / 16bps |
| m | 8 | **24 (baseline research)** |

**E-LIFECYCLE = référence historique uniquement.** Toute expérience future part du PROD lifecycle + m24.

## 5. Baseline research gelée

> **Oracle O0 → Extreme TOP20 (`proba_extreme` rank ≥ 0.80) → LONG-only → PROD lifecycle (stop 2.5×ATR / TP min(3×ATR,7%) / trailing 2.5×ATR / time_stop OFF / gap 3% / 16bps) → m24 → equal-weight 1/24 à budget de risque total constant.**

- Résultats clés (50 seeds) : médiane 61.6%, P10 41.1%, P25 46.8%, P90 88.3%, pire seed +23.5%, PF 1.13, Sharpe 0.45, DD −22.6%, 100% seeds positifs, rolling 12m pire −10.1%.

## 6. Risque résiduel officiel : 2026H1

- 2026H1 reste le semestre faible (mean ≈ −6k, 16-28% seeds positifs) sous toutes les configurations testées.
- m24 réduit la **variance** mais ne corrige pas ce régime/période.
- Les investigations n'ont trouvé **ni filtre PIT rentable ni modification d'exit robuste** pour le résoudre.
- → **Risque résiduel officiel, NON à optimiser maintenant.** Ne pas repartir sur 2026H1 sans un nouveau signal PIT reproductible.

## 7. Gap recherche → production (constat, pas un chantier ouvert)

Le gate Extreme étudié **n'est pas intégré** dans le pipeline production :
- Production = gate **B25** (`global_rank_20 ≥ 0.90` = TOP LONG), pas `proba_extreme`.
- L'Oracle Extreme existe comme **second signal** (`combine.py` : `adjusted_score = f(global_rank_20, P_top)`), **désactivé par défaut** (`DEFAULT_ML_ENABLE_ORACLE_MODEL = False`) ; O0 (sans global_rank_20) ajouté le 2026-08-20.
- Les runs E9→E13 utilisent `proba_extreme` d'un artefact OOS de walk-forward (recherche), pas un chemin live.
- Toute exploitation de m24 nécessiterait un chantier d'intégration séparé (activer l'Oracle O0, basculer la sélection LONG sur le gate Extreme, passer m à 24, sizing equal-weight) — **à décider, hors périmètre de cette synthèse** (la règle « B25 intouchable » du doc Oracle y ferait obstacle).

---

## 8. Garde-fous pour les expériences futures

1. **Gates pré-fixés avant de voir les résultats** (pratique appliquée E6→E13, à conserver).
2. **Lifecycle PROD systématique** (pas d'E-LIFECYCLE sauf référence historique explicite).
3. **Multi-seed systématique** (20+ seeds ; une médiane sans dispersion ne prouve rien).
4. **KPI principal = réduction de la variance inter-seed + P10/P25**, pas le rendement maximal.
5. **Ne pas re-tester** : ranker interne, Y3, EV/Platt, filtre TRUE_BAD, TP/SL/trailing, sauf nouveau mécanisme PIT reproductible.
6. **2026H1 = risque résiduel** : ne pas le « sauver » au prix de la robustesse 2023-2025.
