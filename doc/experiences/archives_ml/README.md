# Archives ML complémentaires

Analyses OOS, backlog et synthèses datées retirés de `doc/ml`. Ils sont non normatifs. Les verdicts durables sont condensés dans le dossier parent ; les architectures actives sont sous `doc/refactor/ml`.

Une recommandation ancienne n’est applicable que si son mécanisme existe encore dans le code et si une validation récente sous le contrat courant la confirme.
