# Archives de recherche complémentaires

Ces fichiers sont des audits de runs, protocoles, verdicts et dossiers de décision datés. Ils sont conservés pour la reproductibilité et pour éviter de répéter des pistes déjà invalidées. Ils ne décrivent pas automatiquement le code, le modèle servi ou la configuration actuelle.

Les enseignements durables sont condensés dans les synthèses du dossier parent. Avant de réutiliser un résultat, retrouver commit, configuration effective, dataset/univers PIT, période, seed, contrat d’exécution et artefacts. Les mentions `GO`, `PROD`, `FROZEN` ou `baseline` restent celles de la date du document.
