Implémente uniquement le pipeline d’entraînement d’un symbole.

Objectif :
- entraîner un modèle pour un symbole donné
- gérer CPU/GPU automatiquement
- sauvegarder :
  - checkpoint
  - scaler
  - config
  - métriques
- enregistrer le run dans MySQL
- ne pas encore orchestrer plusieurs symboles en parallèle

Contraintes :
- fallback CPU obligatoire
- early stopping
- checkpoint best model sur `val_loss`
- structure d’artefacts :
  - `artifacts/models/{symbol}/best.ckpt`
  - `artifacts/models/{symbol}/scaler.pkl`
  - `artifacts/models/{symbol}/config.json`
  - `artifacts/models/{symbol}/metrics.json`
- statut de run en base :
  - pending
  - running
  - success
  - failed
  - skipped

Je veux :
1. un service d’entraînement mono-symbole
2. un service de sauvegarde d’artefacts
3. un logger/registry vers MySQL
4. tests unitaires et/ou d’intégration couvrant :
   - run CPU
   - artefacts écrits
   - statut DB mis à jour
   - gestion d’erreur
   - symbole non entraînable = skipped
