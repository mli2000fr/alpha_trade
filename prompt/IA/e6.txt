- produire une probabilité binaire pour la classe `future_5d_return > 0`
- rendre le modèle compatible avec Lightning

Contraintes :
- entrée : `[batch, seq_len, n_features]`
- encoder LSTM configurable
- attention softmax sur l’axe temporel
- les poids d’attention doivent être récupérables pour inspection
- sortie classification binaire
- code lisible et bien découpé

Je veux :
1. le backbone LSTM
2. le mécanisme d’attention temporelle

4. le LightningModule avec :
   - training_step

   - métriques
   - optimizer
5. tests unitaires couvrant :
   - dimensions forward
   - somme des poids d’attention = 1
   - stabilité sur batch minimal
   - sortie probabiliste valide
