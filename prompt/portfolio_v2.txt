def filter_correlated(
    candidates: list[EnrichedCandidate],
    return_matrix: pd.DataFrame,
    threshold: float,
    min_overlap: int,
) -> tuple[list[EnrichedCandidate], list[CorrelationRejection]]:
    """
    Filtre greedy déterministe.

    Les candidats DOIVENT être triés par conviction_score DESC avant l'appel.

    Algorithme :
      retained = []
      rejections = []
      for each candidate (déjà trié par conviction DESC) :
          if symbol pas dans return_matrix.columns :
              retained.append(candidate)  # pas de données → pas de rejet
              continue
          correlated_with_retained = False
          for each retained_symbol in retained :
              if retained_symbol pas dans return_matrix.columns :
                  continue
              pair_returns = return_matrix[[symbol, retained_symbol]].dropna()
              if len(pair_returns) < min_overlap :
                  continue  # données insuffisantes → pas de rejet
              corr = pair_returns[symbol].corr(pair_returns[retained_symbol])
              if corr > threshold :
                  rejections.append(CorrelationRejection(...))
                  correlated_with_retained = True
                  break  # un seul bloqueur suffit
          if not correlated_with_retained :
              retained.append(candidate)

    Retourne (retained, rejections).
    """

IMPORTANT :
- Corrélation NaN (données insuffisantes) → NE PAS rejeter
- Corrélation négative → NE PAS rejeter
- La logique est O(n²) ce qui est acceptable pour <= 100 candidats

class KellySizer:
    def __init__(self, config: RiskConfig) -> None: ...

    def compute(
        self,
        price_info: PriceInfo,
        predicted_proba: float | None,
        historical_win_rate: float | None,
    ) -> SizingResult:
        """
        Pipeline de calcul :

        1. Probabilité effective :
           pp = predicted_proba or default_win_rate
           wr = historical_win_rate or default_win_rate
           p_eff = prediction_confidence_weight * pp + historical_win_rate_weight * wr
           p_eff = clip(p_eff, 0.001, 0.999)

        2. Si p_eff < min_effective_probability → fallback ATR ou equal_weight

        3. Kelly :
           q = 1 - p_eff
           b = assumed_payoff_ratio
           raw_kelly = p_eff - q / b
           fractional_kelly = max(0, raw_kelly) * kelly_fraction_multiplier
           fractional_kelly = min(fractional_kelly, max_position_weight)

        4. Si fractional_kelly <= 0 → fallback ATR ou equal_weight

        5. Shares Kelly :
           kelly_notional = account_equity * fractional_kelly
           kelly_shares = floor(kelly_notional / price)

        6. Cap ATR (si atr_20 disponible) :
           atr_risk_budget = account_equity * risk_per_trade_pct
           risk_per_share = atr_20 * atr_stop_multiple
           atr_shares_cap = floor(atr_risk_budget / risk_per_share)
           proposed_shares = min(kelly_shares, atr_shares_cap)
           method = "kelly_atr"

        7. Si atr_20 absent :
           proposed_shares = kelly_shares
           method = "kelly_only"

        8. Notional minimum check (min_position_notional)

        9. Retourne SizingResult(symbol, proposed_shares, method)

        Le SizingResult.method DOIT être l'un de :
          "kelly_atr" | "kelly_only" | "atr" | "equal_weight" | "rejected"
        """

Le fallback ATR/equal_weight réutilise la logique EXACTE de PositionSizer.compute().
Tu peux soit appeler PositionSizer en interne, soit dupliquer la logique.
Préférence : composer avec PositionSizer comme fallback interne.

Pipeline V2 dans build() :

  1. Enrichir chaque candidat en EnrichedCandidate (conviction score)
  2. Trier par conviction_score DESC (déterministe)
  3. Appliquer filtre corrélation si return_matrix fourni
     → produire des PortfolioEntry REJECTED pour les rejets corrélation
        avec decision_reason = "corrélation > {seuil} avec {blocker}" (< 255 chars)
  4. Pour chaque candidat retenu après corrélation :
     a. Vérifier prix disponible
     b. Si enable_kelly_sizing → KellySizer.compute()
        Sinon → PositionSizer.compute() (V1 inchangé)
     c. Appliquer ConstraintChecker via RiskCheckerImpl (existant, inchangé)
     d. Produire PortfolioEntry avec TOUS les champs V2 remplis
  5. Retourner la liste complète (ACCEPTED + REDUCED + REJECTED)
