角色設定：
你是一位頂級對沖基金的量化系統架構師，
負責設計「多因子融合選股系統」。

你需要構建 AlphaScanner，
基於「原始K線數據 + 已有因子評分表」進行融合選股。

==================================================
一、數據來源（雙數據源）
==================================================

1. 原始數據（主要）：
表：stock_bars_daily

字段：
- ticker
- date
- close
- volume

--------------------------------------------------

2. 因子評分表（輔助）：
表：stock_scores

字段：
- symbol
- liquidity_val
- relative_strength_index
- historical_range_score
- total_score
- sector
- anomaly_count
- missing_days_count

JOIN 條件：

stock_bars_daily.ticker = stock_scores.symbol

==================================================
二、核心策略（關鍵設計）
==================================================

採用：

👉「重新計算因子 + 融合已有評分」

優先級：

- 原始計算因子（主）
- stock_scores（輔助加權）

==================================================
三、計算流程
==================================================

Step 1：SQL 粗篩（來自 stock_bars_daily）

條件：

- 近20日平均成交額 > 20M
- close > 5
- 至少 252 天數據

--------------------------------------------------

Step 2：Python 計算因子（核心）

計算：

- MA50 / MA150 / MA200
- 52週高低
- Volatility Ratio（10日 / 60日）

--------------------------------------------------

Step 3：趨勢模板（Minervini）

輸出：

trend_score（0~1）

--------------------------------------------------

Step 4：VCP 壓縮

條件：

Volatility_Ratio < 0.6

輸出：

vcp_score（0~1）

--------------------------------------------------

Step 5：融合已有因子（關鍵）

定義最終分數：

final_score =

0.5 * (trend_score + vcp_score)
+ 0.3 * stock_scores.total_score
+ 0.2 * stock_scores.relative_strength_index

注意：

- 所有 score 必須標準化到 0~1
- 若 stock_scores 缺失，則只使用計算因子

==================================================
四、過濾條件（結合 stock_scores）
==================================================

- anomaly_count < 5
- missing_days_count < 10
- liquidity_val > 20M（雙重確認）

==================================================
五、板塊中性化
==================================================

- 每個 sector ≤ 30%
- 使用 round-robin 或 greedy 分配
- 最終選出 50 檔

==================================================
六、數據庫回寫（重要）
==================================================

更新 stock_scores：

1. 全部設為 0：

UPDATE stock_scores SET is_candidate = 0;

2. 更新入選：

UPDATE stock_scores
SET is_candidate = 1,
    last_updated_scan = NOW()
WHERE symbol IN (...)

必須：

- 使用 transaction
- 批量更新
- 避免長時間鎖表

==================================================
七、工程要求

- 使用 chunking（不可全量載入）
- 可使用 ThreadPoolExecutor
