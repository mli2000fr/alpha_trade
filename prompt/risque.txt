# COMPORTEMENT ATTENDU

## 1. Chargement des candidats
Lire depuis `stock_scores` :
- `WHERE is_candidate = 1`
- score = `COALESCE(final_score_sentiment, final_score)`
- trier par score décroissant

## 2. Filtres de qualité
Exclure ou pénaliser les symboles si :
- `anomaly_count` dépasse un seuil configuré
- `missing_days_count` dépasse un seuil configuré

## 3. Sizing
Implémenter un `PositionSizer` avec :
- sizing principal basé sur ATR(20)
- formule recommandée :

```python
risk_budget_dollars = account_equity * risk_per_trade_pct
risk_per_share = atr_20 * atr_stop_multiple
shares = floor(risk_budget_dollars / risk_per_share)
```

- fallback si ATR indisponible :
  - equal-weight simple
- min 1 share sinon rejet
- pas de position si `price <= 0`

## 4. Contraintes de risque
Implémenter au minimum :
- `max_positions`
- `max_position_weight`
- `max_sector_weight`
- `max_gross_exposure`
- `min_position_notional`
- blocage si circuit breaker actif

## 5. Circuit breaker
Prévoir :
- `max_portfolio_drawdown_pct`
- `max_daily_loss_pct`

Même si l’historique PnL complet n’existe pas encore, créer une implémentation propre et extensible avec fallback configurable.

## 6. RiskChecker
Implémenter une classe concrète `RiskCheckerImpl` :
- applique toutes les règles
- peut réduire une taille proposée
- peut rejeter une position
- expose `is_circuit_breaker_active()`

## 7. Construction du portefeuille
Créer un `PortfolioBuilder` qui :
- prend les candidats triés
- calcule un sizing
- applique le risk checker
- construit le portefeuille final jusqu’à `max_positions`

Sortie minimum :
- `symbol`
- `sector`
- `entry_price`
- `score_used`
- `score_source`
- `atr_20`
- `proposed_shares`
- `approved_shares`
- `target_notional`
- `target_weight`
- `decision`
- `decision_reason`

## 8. Audit SQL
Créer une table `risk_decisions` qui journalise chaque décision :
- `run_id`
- `trade_date`
- `symbol`
- `decision`
- `reason`
- `score_used`
- `score_source`
- `entry_price`
- `proposed_shares`
- `approved_shares`
- `target_weight`
- `sector`
- `created_at`

Créer une table `portfolio_targets` :
- `run_id`
- `trade_date`
- `symbol`
- `shares`
- `entry_price`
- `target_weight`
- `sector`
- `score_used`
- `score_source`
- `created_at`
