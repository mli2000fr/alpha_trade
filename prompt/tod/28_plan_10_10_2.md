## 8. Risques & mitigations

| Risque | Probabilité | Impact | Mitigation |
|---|---|---|---|
| Refactor `_execution_center.py` casse silencieusement la page la plus utilisée | Élevée | Élevé | AppTest exhaustif **avant** découpage ; revue manuelle pas-à-pas par opérateur. |
| TLAPS hors compétence équipe | Élevée | Moyen | Consultant externe 5-10 j/h ; alternative : enrichir Z3 (déjà maîtrisé). |
| Audit externe humain coûteux | Moyenne | Élevé | Pré-audit interne en S24 pour anticiper. Budget : 5-10 k€. |
| Couverture branches > 90 % génère beaucoup de tests cosmétiques | Élevée | Moyen | Pragmatique : 90 % global, 95 % critique ; exclure code non-prod. |
| IBKR `submit_order` exige fees market data | Moyenne | Moyen | Limiter à paper TWS pour tests automatisés ; live IBKR optionnel. |
| Async DB I/O introduit régressions | Moyenne | Élevé | POC restreint à 3 loaders read-only ; toggle env var. |
| Mutation testing > 70 % difficile sur code legacy | Élevée | Moyen | Itérer module par module ; baseline 50 % puis 70 %. |
