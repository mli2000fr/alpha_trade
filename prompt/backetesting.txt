🚀 Comment lancer le backtest
# Backtest complet 10 ans, paramètres production (TP=8%, TS=5%, 20 positions)
python -m backtesting run --start 2016-01-01 --end 2026-04-20 --equity 100000

# Backtest personnalisé
python -m backtesting run --start 2020-01-01 --end 2026-04-20 --equity 50000 --tp 0.10 --ts 0.04 --max-positions 15

# Sans sauvegarder les artefacts (console uniquement)
python -m backtesting run --start 2023-01-01 --no-save


Prérequis : la base MySQL doit contenir les données historiques (stock_bars_daily, stock_scores, model_predictions). Les variables d'env LOGIN_DB / PASSWORD_DB doivent être définies.
Artefacts générés dans artifacts/backtesting/ :
equity_curve.png — courbe de valeur du portefeuille
trades.csv — liste détaillée de tous les trades
Lancer les tests :
python -m pytest tests/test_backtesting.py -v
