# Futur modèle exécuté localement

Emplacement réservé aux futurs prompts du modèle local. Aucun prompt local ni
client d'inférence n'est actuellement enregistré ou activé pour cette famille.

Créer plus tard un sous-répertoire de version et une entrée `runtime: local`
dans `../../catalog.json`.
Le prompt sera indépendant des versions cloud ; aucun texte cloud ne sera
utilisé automatiquement à sa place.
